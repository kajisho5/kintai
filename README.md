# Kintai

勤怠管理システム。CYBER XEED など既存製品を調査し（[docs/competitor-research.md](docs/competitor-research.md)）、
小規模企業向け・セルフホスト可能な代替を目指しています。

## 構成

| パス | 内容 |
|---|---|
| `src/engine` | 労働時間集計エンジン。日次／週40h／月次、深夜、法定休日、36協定チェック、有給付与。DB・UI非依存の純関数（テスト付き） |
| `src/app` | 画面（React + Vite）。ダッシュボード（本日の勤務ダイヤ）、打刻、勤怠一覧と個人明細、申請・承認、有給管理 |

## 起動

```
npm install
npm run dev        # 開発サーバー
npm run build      # 型チェック + 本番ビルド
npm test           # エンジンのテスト
```

## 現状と制約

- 画面のデータは**サンプル**（決定論的に生成。実在の人物・企業とは無関係）。集計値はすべて `src/engine` を通して算出しています。
- 打刻・承認の操作はブラウザの localStorage に保存されるデモです。サーバー／DB／認証は未実装です。
- 当月の集計は前日までです。月末見込は「当月実績の日割り」と「直近3か月の平均」を、経過営業日数で重み付けして算出しています。
- 祝日は2026年分のみ登録しています。変形労働時間制・フレックスの精算期間・端数処理は未実装です。
- 労働基準法に関する数値（付与日数表、36協定上限など）は実運用前に社労士等による確認が必要です。
