# トキスケ ロゴ・ブランドの使い方

製品名は「トキスケ」（ローマ字は `tokisuke`、すべて小文字）。「時（トキ）を助ける（スケ）」。ロゴ・色・文字・部品は、デザインシステム（claude.ai の「トキスケ デザインシステム」）にもまとめています。

> **未実施**: 商標の調査（J-PlatPat、第9類・第42類）。公開・印刷の前に必ず行ってください。ロゴの図は、社内で作った仮の最終版で、専門のデザイナーによる仕上げは受けていません。

## ロゴの考え方

- 「tokisuke」の **o が時計**。針は朱の1本だけ（o'clock＝〜時ちょうど）。
- アプリアイコンは、藍の角丸の正方形に白の「**to**」。「と」と読め、名前の頭の音。
- 朱は、打刻（判子を押す瞬間）のためだけの色。ロゴでは、針の1点だけ。

## ファイル（`brand/`）

| ファイル | 使いどころ |
|---|---|
| `logo/tokisuke-wordmark.svg` | 文字ロゴ（標準）。ヘッダー・資料 |
| `logo/tokisuke-horizontal.svg` | アイコン＋文字の横組み。名刺・請求書・メール署名 |
| `logo/tokisuke-stacked.svg` | 縦組み。正方形に近い場所 |
| `logo/tokisuke-icon.svg` | アプリアイコン（32px より大きい） |
| `logo/tokisuke-icon-small.svg` | 小さい用（16〜32px。線を太くし、針を大きくした版）。ファビコン |
| `logo/tokisuke-wordmark-black.svg` / `-white.svg` | 一色（黒・白）。単色印刷・刺繍・FAX |
| `logo/tokisuke-wordmark-reversed.svg` / `tokisuke-horizontal-reversed.svg` | 暗い背景用（白の文字、針は明るい朱） |
| `logo/tokisuke-icon-mono.svg` | 一色のアイコン |
| `logo/tokisuke-glyph-white.svg` | 色つきの面（タイル）の上に置く、白の「to」 |
| `web/` | ファビコン・PWA アイコン一式と `head-snippet.html`、`site.webmanifest` |
| `presentation/` | 使用例の見本（5枚） |
| `build_logo.py` | ロゴの生成スクリプト（寸法・形はここが元。`pip install skia-pathops fonttools cairosvg`） |

SVG は、線ではなく、塗りの輪郭（アウトライン）です。文字（フォント）に依存しません。PNG も同じ場所にあります。

## 色

| 名前 | HEX | 使いどころ |
|---|---|---|
| 藍墨（ink） | `#1B2A41` | 文字ロゴ |
| 藍（ai） | `#27498C` | アプリアイコンの地 |
| 朱（shu） | `#C73F28` | 時計の針（白・明るい背景） |
| 朱・暗い背景用 | `#F27A63` | 時計の針（暗い背景・藍の地の上） |
| 白 | `#FFFFFF` | アイコンの「to」 |

CMYK・特色（Pantone など）は、まだ決めていません。印刷会社で、色校正をしたうえで決めてください。

## 余白と最小サイズ

- **余白**: ロゴの周りに、文字の x の高さ（小文字の「o」の高さ）以上の余白をとる。アイコンは、アイコンの幅の 1/4 以上。
- **最小サイズ**:
  - 文字ロゴ: 幅 96px（印刷は 25mm）
  - 横組み: 幅 120px（印刷は 30mm）
  - 縦組み: 幅 80px（印刷は 20mm）
  - アイコン: 32px まではふつうの版、**16〜32px は「小さい用」**を使う
- 小さい用の版は、16px でも「to」と読めることを確認済み（16・32・48px で、拡大して確認）。

## 背景

- 白・明るい面（`#F5F7FA` など）: 標準のロゴ（藍墨の文字、朱の針）。
- 暗い面（藍墨・黒に近い色）: reversed（白の文字、明るい朱の針）。
- 写真や、色の濃い面: 一色の白か黒。針も同じ色にする。
- 朱の面の上には、置かない（針が見えなくなる）。

## してはいけないこと

- 色を変える（針を藍にする、文字を朱にする など）。針の色を増やさない。
- 針の向き・長さ・太さを変える。「o」に針を足さない。
- 文字を別の書体で組み直す。縦横に引き伸ばす。傾ける。
- 影・光彩・グラデーション・枠線を付ける。
- アイコンの「to」の間隔や、タイルの角丸を変える。
- 暗い背景に、標準（藍墨の文字）のロゴを置く。

## 既知の限界

- 文字は、市販の書体ではなく、線の太さをそろえた丸い形で、スクリプトで作図したもの。字間は、目で調整しており、プロの書体設計ほどの磨きはありません。
- 針の見えやすさ: 文字ロゴでは、針が小さく、遠目には普通の「o」に見えます（洒落として気づく人だけが気づく、という設計）。小さい用のアイコンでは、針を大きくしています。
