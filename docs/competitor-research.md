## 4. 機能の整理（共通コア vs 差別化）

共通コア（どの製品にもある）
1. 打刻（Web / スマホ / ICカード / GPS）
2. 労働時間集計（法定内・時間外・深夜・休日、休憩控除）
3. 申請承認（打刻修正・残業・休暇）
4. 有給管理（付与・残日数・年5日取得義務）
5. 36協定アラート
6. シフト管理
7. 給与ソフト向けCSV出力

差別化の余地
- 小規模向けの低価格/無料枠 + 初期費用0
- セルフホスト可能（データ主権）
- 法改正に追随しやすい**純関数の集計エンジン**（テスト容易）
- API / MCP 公開による外部連携

## 5. 本プロジェクトの方針（案）

- **MVP**: 打刻 → 日次集計 → 月次集計 → 36協定アラート → 有給管理 → CSV出力
- **第1段階（実装済み）**: 労働時間集計エンジン（`src/engine`）。DB・UI非依存の純関数とテスト
- **次段階**: API + DB + 画面（技術スタックは未決定。候補: TypeScript + Hono + SQLite/Postgres + React）
