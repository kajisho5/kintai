# 労働時間の計算ルール 確認用資料（社会保険労務士・顧問弁護士向け）

作成日: 2026-10-06 ／ 対象: 勤怠管理SaaS「Kintai」（仮名）の `src/engine`・`src/domain`

この資料は、システムが**どのルールで労働時間を集計・判定しているか**を一覧にし、専門家に**確認してほしい点**を明確にするためのものです。
システムの集計・警告は参考情報であり、法的判断を保証するものではありません。公開前に、この資料の内容を確認してください。

- 「計算例」の数値は、手計算ではなく、実際の計算エンジンを動かして出した値です（再現方法は末尾）。
- 「根拠」は、確認に使った公開資料です。**一次資料（条文・通達の全文）まで確認できたものと、解説記事・検索結果の要約までしか確認できていないものを分けて記載**しています。後者は、特に確認をお願いします。

## 1. システムが計算するもの／しないもの

| 計算する | 計算しない |
|---|---|
| 実労働時間（休憩を除く）、法定内、時間外、深夜（22〜5時）、法定休日労働 | **割増賃金の金額**（割増率の適用・60時間超50%・賃金の端数処理） |
| 日・週・変形期間・清算期間の時間外の判定 | 遅刻・早退・欠勤の控除 |
| 36協定の限度（月・年・特別条項の回数・単月100時間未満・2〜6か月平均80時間）との照合 | 36協定の締結・届出そのものの有無（特別条項の有無は設定で受け取る） |
| 有給休暇の付与日数・残日数・年5日の取得義務の進み具合 | 有給の賃金、時季指定の運用 |

時間外の時間数は、給与計算の入力として使われる想定です。法定内残業（所定を超えるが法定内）の区別は、`法定内` 欄との差で分かりますが、会社の所定労働時間は集計に使っていません（フレックス・変形では、予定の所定時間との差を表示のみ）。

## 2. 判定ルール

### 2.1 通常の勤務（固定時間制）

| 項目 | 判定 | 根拠 |
|---|---|---|
| 日 | 1日の実労働が8時間を超えた分が時間外 | 労基法32条2項 |
| 週 | 週（月曜〜日曜）の実労働のうち、日の時間外を除いた分が40時間を超えた分が時間外。超えた日に付ける | 労基法32条1項 |
| 深夜 | 22:00〜翌5:00 の実労働（時間外・休日と重複して数える） | 労基法37条 |
| 法定休日 | 暦日（0〜24時）で判定。法定休日の労働は時間外に含めず別に集計。会社設定の曜日（既定は日曜）、または、シフトで週ごとに指定した日 | 労基法35条、[昭63.1.1基発第1号](https://www.mhlw.go.jp/web/t_doc?dataId=00tb1899&dataType=1&pageNo=1)（全文は未確認。検索結果の要約で確認） |
| 月・週の区切り | 月（または会社の締め日で区切った期間）をまたぐ週は、前後の週も含めて判定し、時間外は**超えた日の月**に付ける | システムの設計判断（要確認、§4-1） |

### 2.2 変形労働時間制（1か月単位・1年単位・1週間単位）

あらかじめ定めた日ごとの所定労働時間（シフト）をもとに、次の3段階で、**重複して数えない**ように判定します。

1. **日**: 所定が8時間を超える日は、その所定を超えた分。それ以外の日は、8時間を超えた分。
2. **週**: 所定の週合計が40時間を超える週は、その所定を超えた分。それ以外の週は、40時間を超えた分。ただし日の時間外を除く。変形期間の途中から始まる週・途中で終わる週は、この判定をしない。
3. **期間**: 法定労働時間の総枠（40時間 × 期間の日数 ÷ 7。1分未満切捨て）を超えた分。ただし日・週の時間外を除く。

| 区分 | 期間 | 根拠 |
|---|---|---|
| 1か月単位 | 暦月（または締め日で区切った月） | [厚生労働省 静岡労働局の資料](https://jsite.mhlw.go.jp/shizuoka-roudoukyoku/var/rev0/0123/3919/2017111615407.pdf)（検索結果の要約で確認。PDFの全文は未確認） |
| 1年単位 | 会社設定の起点月の1日から12か月 | [厚生労働省「1年単位の変形労働時間制」](https://www.mhlw.go.jp/shinsai_jouhou/faq_03.html)（要約で確認） |
| 1週間単位 | 週（月曜〜日曜）ごとに独立 | 労基法32条の5（条文は未確認。週ごとに「日・週」の判定をする実装） |

時間外は「累計がしきい値を超えた日」に付けます。累計は減らないため、期間の途中でも、そこまでの時間外は確定した値になります。

### 2.3 フレックスタイム制

| 項目 | 判定 | 根拠 |
|---|---|---|
| 清算期間 | 1〜3か月（会社設定。起点月から区切る） | 労基法32条の3（2019年改正） |
| 時間外 | 清算期間の総枠（40時間 × 日数 ÷ 7）を超えた分。日・週の判定はしない | [厚生労働省 滋賀労働局の解説](https://jsite.mhlw.go.jp/shiga-roudoukyoku/content/contents/000380237.pdf)（要約で確認） |
| 1か月超の清算期間 | 上に加えて、各月の実労働が週平均50時間（50時間 × 月の日数 ÷ 7）を超えた分を、その月の時間外とする。総枠の超過とは重複しない | 同上 |
| コアタイム | 出勤・退勤が間に合わなかった日は、勤怠の備考に「コアタイム外」と表示するだけ（集計に影響しない） | — |

### 2.4 週の法定労働時間44時間（特例措置対象事業場）

会社設定で有効にすると、週の法定労働時間を44時間とします。日の8時間は変えません。**適用する範囲**は、通常の勤務・1か月単位の変形・清算期間が1か月以内のフレックスのみで、1年単位・1週間単位の変形と、清算期間が1か月を超えるフレックスは40時間のままです。
根拠: 労基則25条の2（[条文](https://www.mhlw.go.jp/web/t_doc?dataId=73023000&dataType=0&pageNo=1)。第1項〜第3項は確認。**1週間単位の変形が対象外であることは、条文に規定が無いことからの推定**）。

### 2.5 36協定の限度

| 項目 | 判定 | 根拠 |
|---|---|---|
| 原則 | 時間外労働が月45時間・年360時間まで（休日労働を含まない） | 労基法36条4項 |
| 対象期間が3か月を超える1年単位の変形 | 月42時間・年320時間 | 労基法36条4項（[解説](https://www.nbc.or.jp/news/20231116_6682/)で確認。条文は未確認） |
| 特別条項（設定でオン） | 月45時間（変形は42時間）超は年6回まで／年720時間まで | 労基法36条5項 |
| 常に適用 | 単月の時間外＋休日労働が100時間未満／2〜6か月の平均が80時間以内 | 労基法36条6項 |
| 年の起算 | 会社設定の起算月から数える | — |
| 警告 | 上限の80%に達すると「注意」、超えると「違反」 | システムの設計 |

月末見込は、これまでの実績が所定の何倍だったか（ペース）を、残りの予定に当てはめた推計です（参考表示）。

### 2.6 端数処理

会社設定で有効にすると、**月合計**の時間外・休日・深夜のそれぞれについて、1時間未満の端数を30分未満切捨て・30分以上切上げにします。日ごと・打刻ごとの丸めは、できません。36協定の判定は丸めずに実時間で行います。
根拠: 昭63.3.14基発150（解説の要約による。**原文は未確認**）。

### 2.7 締め日

月の区切りを、月末または1〜28日の締め日にします（例: 20日締めの10月分 = 9/21〜10/20）。月の時間外・36協定の月の判定・フレックスの清算期間・1年単位の期間は、この区切りに従います。

### 2.8 有給休暇

付与日数（通常・比例付与）、年5日の取得義務の進み具合を表示します。付与日数表は労基法39条の表に基づく実装ですが、**この資料の作成時には条文との再照合をしていません**。全労働日の8割出勤の判定は、出勤率95%固定の簡易実装です（§4-7）。

## 3. 計算例（エンジンの出力）

### 3.1 夜勤・日またぎ（休日は暦日で切り分け）

| ケース | 実働 | 法定内 | 日の時間外 | 法定休日労働 | 深夜 |
|---|---|---|---|---|---|
| 平日 22:00→翌7:00、休憩1h（25:00〜26:00） | 8:00 | 8:00 | 0:00 | 0:00 | 6:00 |
| 土曜 22:00→日曜（法定休日）7:00、休憩なし | 9:00 | 2:00 | 0:00 | 7:00（日曜0時以降） | 7:00 |
| 日曜（法定休日）20:00→月曜6:00、休憩1h | 9:00 | 5:00（月曜側） | 0:00 | 4:00（日曜側） | 6:00 |

日またぎの勤務は始業日の1日の労働として扱い（昭63.1.1基発第1号）、法定休日にかかる部分だけを休日労働にしています。

### 3.2 1か月単位の変形（2026年10月、31日）

所定: 月〜木 10時間、金 8時間（土日は所定なし）。実績: 月〜木 所定どおり、10/9（金）9.5時間、10/10（土）4時間、10/3（土、月初の部分週）4時間。

| 項目 | 値 |
|---|---|
| 法定労働時間の総枠（40h × 31 ÷ 7） | 177:08 |
| 期間内の実労働（法定休日を除く） | 219:30 |
| 日の時間外 | 1:30（10/9: 所定8時間のところ9.5時間） |
| 週の時間外 | 4:00（10/10: 週の所定40時間のところ、土曜の4時間） |
| 期間の時間外 | 36:52（= 219:30 − 1:30 − 4:00 − 177:08。累計が総枠を超えた 10/27〜10/30 に付く） |

### 3.3 フレックスタイム制

**清算期間1か月（10月）**: 平日22日、毎日9時間15分（日8時間超でも日の時間外にならない）。総枠 177:08、実労働 203:30 → 時間外 **26:22**。

**清算期間3か月（10〜12月、92日）**: 総枠 525:42。10月の各月上限（50時間 × 31 ÷ 7）= 221:25。10月は毎日10時間30分（実労働が上限を超える）、11〜12月は毎日7時間。
10月の時間外 9:35（月の上限超過）、期間全体の時間外 13:18（総枠 525:42 に対し、実労働 539:00 のうち月の超過分を除いて判定。重複なし）。

### 3.4 36協定

| ケース | システムの表示 |
|---|---|
| 特別条項なし・月50時間 | 「時間外労働が月45時間を超えています」（違反） |
| 特別条項あり・月45時間超が7か月 | 「月45時間超が年6回を超えています」（違反） |
| 1年単位の変形・月43時間 | 「時間外労働が月42時間を超えています」（違反） |
| 時間外70時間＋休日30時間 | 「時間外+休日労働が月100時間以上です（法違反）」 |

総枠の例: 28日 = 160:00、30日 = 171:25、31日 = 177:08、92日 = 525:42、365日 = 2085:42。

## 4. 確認してほしい点（簡略化・前提）

実運用に影響しうるものから順に並べています。「どう判断するか」を教えていただければ、設定または実装を直します。

1. **月・締め日をまたぐ週の扱い**（§2.1）— 週の判定は月曜〜日曜、時間外は超えた日の月に付けます。法定休日の週だけは日曜〜土曜（通達の既定）で判定しています。就業規則の週の起算日と合っていなければ、設定項目として追加します。
2. **変形期間の端の週**（§2.2）— 期間の途中から始まる週・途中で終わる週は、週の判定をせず、期間の総枠だけで判定しています。通達上の正しい扱いを確認したい。
3. **1年単位の変形の要件**（§2.2）— 労働日数の上限（280日）、1日10時間・週52時間の上限、連続労働日数、週48時間超の制限、対象期間の労使協定・届出は**チェックしていません**。シフトの作成・届出は運用側の責任になります。警告として実装すべきか。
4. **1年単位の変形期間の途中での入退社の清算**（賃金の精算）は扱いません。
5. **交替制の休日の特例**（8時間3交替などで、番方による休日を継続24時間とする特例）は扱わず、休日は暦日で判定しています。夜勤中心の会社では影響が大きい。
6. **週44時間の特例の適用範囲**（§2.4）— 1週間単位の変形を対象外としている点の確認。
7. **有給の付与判定**（§2.8）— 出勤率の判定を、実際の出勤状況ではなく95%固定としています。付与日数表を条文と再照合してください。
8. **フレックスの不足時間の繰越**、コアタイム・フレキシブルタイムの違反判定は、表示・注記のみで、集計に影響しません。
9. **月60時間超の割増**（中小企業は2023年4月から適用）の判定に必要な「月60時間超の時間外」は集計していますが、割増賃金の計算は行いません。
10. **打刻の端数・みなし**（始業前の打刻、終業後の打刻と実際の勤務の差）は扱わず、打刻した時刻をそのまま使います。修正は、申請と承認の記録で行います。
11. **法定休日の指定の方法**— 会社設定の曜日、または、シフトで週ごとに指定した日です。就業規則に定める方法と合っているか。
12. **設定変更の遡及** — 締め日・協定期間・清算期間などの設定変更は、過去の月にも適用されます（履歴を持たない）。確定した月の扱いに問題が無いか。

## 6. 計算例の再現方法

```
npx tsx <例のスクリプト>   # src/engine の calcDay / calcVariablePeriod / calcFlexPeriod / check36 を呼ぶ
npm test                  # 計算ルールのテスト（src/engine/*.test.ts、src/domain/*.test.ts）
```

テストは、上記の各ルールを、境界の値で確かめています（例: 総枠の端数、週をまたぐ月、法定休日の暦日の切り分け、清算期間1か月超の重複しない判定）。
